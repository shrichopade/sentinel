Prompt 2
Add the agentic loop to orchestrator.py
orchestrate() + execute_tool() dispatcher — the core loop pattern
Cursor prompt
Add two functions to backend/agents/orchestrator.py. The file already has ORCHESTRATOR_TOOLS and ORCHESTRATOR_SYSTEM — append below them. Function 1: async def orchestrate(trigger: dict, user_id: str = "dev") -> dict This is the agentic loop. It calls Claude, checks the stop_reason, executes any requested tools, feeds results back, and repeats until Claude stops. The trigger dict always contains: document_id (str), vendor_name (str), document_type (str), domain (str). Implementation: 1. Build a working_memory dict: {"trigger": trigger, "steps": [], "findings": [], "risk_score": None, "action_item": None} 2. Build the initial messages list with a single user message telling Claude to analyse the document (include document_id, document_type, vendor_name from trigger). 3. Set MAX_ITERATIONS = 10 as a safety limit. 4. Enter a while loop (iteration < MAX_ITERATIONS): a. Increment iteration counter. b. Call client.messages.create() with model="claude-sonnet-4-20250514", max_tokens=2000, system=ORCHESTRATOR_SYSTEM, tools=ORCHESTRATOR_TOOLS, messages=messages. c. Append the response to messages as: {"role": "assistant", "content": response.content} d. If response.stop_reason == "end_turn": break e. If response.stop_reason == "tool_use": - Create an empty tool_results list. - Loop over response.content. For each block where block.type == "tool_use": * Print: f" [Loop] Calling tool: {block.name}" * Call result = await execute_tool(block.name, block.input, working_memory, user_id) * Import and call log_step from agents.step_logger (document_id from trigger, tool_name=block.name, summary=str(result)[:200], user_id) * Append to working_memory["steps"]: {"tool": block.name, "input": block.input, "output_summary": str(result)[:200]} * Append to tool_results: {"type": "tool_result", "tool_use_id": block.id, "content": json.dumps(result)} - Append to messages: {"role": "user", "content": tool_results} 5. After the loop, return working_memory. Function 2: async def execute_tool(tool_name: str, tool_input: dict, working_memory: dict, user_id: str) -> dict A dispatcher that routes each tool name to the correct sub-agent function. Import sub-agent functions inside the function body (not at the top of the file) to avoid circular imports. from agents.sub_agents import (contract_analyst, research_agent, risk_scorer, negotiation_drafter, create_action_item) Routing: - "invoke_contract_analyst" → call contract_analyst(document_id=tool_input["document_id"], focus_areas=tool_input.get("focus_areas", [])). Store result["findings"] into working_memory["findings"]. - "invoke_research_agent" → call research_agent(query=tool_input["query"], jurisdiction=tool_input.get("jurisdiction", "GB")) - "invoke_risk_scorer" → call risk_scorer(findings=tool_input["findings"], document_type=tool_input["document_type"]). Store result["score"] into working_memory["risk_score"]. - "invoke_negotiation_drafter" → call negotiation_drafter(action_type=tool_input["action_type"], context=tool_input["context"]) - "create_action_item" → call create_action_item(tool_input=tool_input, user_id=user_id, document_id=working_memory["trigger"]["document_id"]). Store result into working_memory["action_item"]. - Default: return {"error": f"Unknown tool: {tool_name}"} Each branch should return the result of the sub-agent call directly.
This is the most important prompt of Day 2. Read the generated code carefully before moving on — make sure the while loop appends both the assistant response AND the tool results to the messages list. If either is missing, the loop will either run forever or produce wrong outputs.

Cursor prompt
One or more sub-agents in backend/agents/sub_agents.py are throwing JSONDecodeError when trying to parse Claude's response. Claude is returning JSON wrapped in markdown code fences like ```json ... ``` instead of raw JSON. For each sub-agent function (contract_analyst, research_agent, risk_scorer, negotiation_drafter), update the JSON parsing section to: 1. Get the raw text: text = response.content[0].text.strip() 2.
