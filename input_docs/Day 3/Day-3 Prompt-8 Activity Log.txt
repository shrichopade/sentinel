Add a new endpoint to backend/api/actions.py.

GET /activity
- Optional query parameter: document_id (string, default None)
- Query the Supabase "agent_steps" table
- If document_id is provided, filter by that document_id
- Always order by created_at descending (newest first)
- For each row, construct a "link" field: if document_id is set on the row, set link = "/vault?doc=" + document_id, else link = None
- Return a list of objects with fields: id, document_id, agent_name, tool_called, summary, created_at, link
- Also add a computed field "is_autonomous": true if tool_called does not equal "create_action_item", false if it does (the action item creation is the human-triggered checkpoint)

Also mount this new router in backend/api/main.py if it is not already included — add: from api.actions import router as actions_router and app.include_router(actions_router) if not present.
