Create the file backend/agents/guardrails.py for the PCGA project.

This file is a post-processing pipeline that runs on every agent output before it reaches the user or the actions table. It never blocks output — it annotates it with warnings.

Implement the following four functions and a main entry point:

1. find_uncited_claims(text: str) -> list[str]
   Scan the text for sentences that make a factual claim (contains a number, a date, a vendor name, or a legal term) but do not include a citation marker in the format [N] or [Source]. Return a list of the offending sentences.

2. inject_legal_caveat(content: str, output_type: str) -> str
   If output_type is one of "risk_assessment", "letter_draft", or "legal_finding", append this exact string to the content on a new line: "\n\n---\nAI-generated summary. Review with a qualified professional before acting."
   Return the content unchanged for all other output types.

3. redact_pii(content: str) -> tuple[str, list[str]]
   Use regex to find and replace common UK personal identifiers:
   - National Insurance numbers (pattern: two letters, six digits, one letter — e.g. AB123456C) → replace with [REDACTED-NI]
   - Sort codes (pattern: XX-XX-XX where X is a digit) → replace with [REDACTED-SORT-CODE]
   - 8-digit strings that look like bank account numbers when near the word "account" → replace with [REDACTED-ACCOUNT]
   Return a tuple of (redacted_content, list_of_what_was_found).

4. check_scope_escalation(content: str) -> tuple[bool, str]
   Check the content for phrases that imply actions beyond the system's authority: "take legal action", "sue", "file a police report", "contact the Financial Ombudsman", "go to court", "file a claim", "seek legal counsel". If any are found, return (True, "This situation may require professional legal or financial advice."). Otherwise return (False, "").

5. apply_guardrails(output: dict, output_type: str) -> dict
   Main entry point. The output dict always has a "content" field (string) and may have a "warnings" list (create it if absent).
   Run all four checks in sequence:
   - Citation check: if uncited claims found, append warning message and mark each offending sentence in the content with a ⚠ prefix.
   - Caveat injection: always run, replaces content in place.
   - PII redaction: if PII found, replace in content and append warning listing what was redacted.
   - Scope check: if escalation needed, set output["escalate"] = True and output["escalation_reason"] = the reason string.
   Return the modified output dict.

Use only Python standard library (re, typing). No external dependencies.
Add a LEGAL_CAVEAT constant at the top of the file holding the caveat string.
